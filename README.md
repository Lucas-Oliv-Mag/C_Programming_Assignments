## 📌 Sobre o Repositório

Este repositório foi criado para centralizar, organizar e documentar todas as lições, exercícios práticos, laboratórios e projetos desenvolvidos durante a disciplina de **Algoritmos e Programação** do 1º semestre de Engenharia Elétrica.

O objetivo principal é solidificar a base de lógica de programação com a linguagem C, essencial para o desenvolvimento de firmware, automação, sistemas embarcados ao longo do curso.
